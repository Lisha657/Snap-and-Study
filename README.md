# 📚 Snap & Study

Snap & Study is an AI-powered learning assistant that helps students understand difficult questions, diagrams, notes, and PDFs through simple, step-by-step explanations. Students can also email AI-generated study summaries for later revision.

## Features

- Upload photos of questions, diagrams, and handwritten notes.
- Upload PDF documents containing study materials.
- Get simple explanations powered by Google Gemini AI.
- Ask follow-up questions through an interactive chat interface.
- Generate study summaries from the conversation.
- Email explanations and summaries using Gmail.

## Technologies Used

- Streamlit
- Google Gemini AI

## Setup Instructions

### 1. Clone the Repository

- Open a terminal.
- Run the following commands:

```bash
git clone https://github.com/Lisha657/Snap-and-Study.git
cd Snap-and-Study
```

### 2. Create a Virtual Environment

- Create a Python virtual environment:

```bash
python -m venv venv
```

- Activate the environment on Windows:

```powershell
.\venv\Scripts\Activate.ps1
```

### 3. Install Dependencies

- Install the required Python packages:

```bash
pip install -r requirements.txt
```

### 4. Configure API Credentials

- Create a folder named `.streamlit` in the project directory.
- Create a file named `secrets.toml` inside that folder.
- Add the following configuration:

```toml
GEMINI_API_KEY = "your_gemini_api_key"
GMAIL_ADDRESS = "your_gmail_address"
GMAIL_APP_PASSWORD = "your_gmail_app_password"
```

- Obtain a Gemini API key from [Google AI Studio](https://aistudio.google.com/apikey).
- Generate a Gmail App Password from [Google Account App Passwords](https://myaccount.google.com/apppasswords).
- Replace the example values with your actual credentials.

### 5. Run the Application

- Start the Streamlit application:

```bash
streamlit run app.py
```

- Open the local URL displayed in the terminal.
- Enter your name and email address.
- Upload a study photo or PDF, or type a question.
- Read the explanation generated by Gemini.
- Click **Send to Email** to receive the study summary.

## Deployment on Streamlit Community Cloud

- Push the project files to GitHub.
- Open [Streamlit Community Cloud](https://share.streamlit.io/).
- Sign in using your GitHub account.
- Select the `Lisha657/Snap-and-Study` repository.
- Choose the `main` branch.
- Set the main file path to `app.py`.
- Add the Gemini API key and Gmail credentials under the app's **Secrets** settings.
- Click **Deploy**.

## Security

- Never upload `.streamlit/secrets.toml` to GitHub.
- Keep API keys and Gmail App Passwords private.
- Ensure `.gitignore` excludes `.streamlit/secrets.toml`, `venv/`, and `__pycache__/`.
